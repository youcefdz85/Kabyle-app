# Recordings

One file per phrase, named `<lessonId>-<phraseId>.<ext>`, for example
`greetings-azul.m4a`. The supported formats are mp3, m4a, webm and ogg.

The easiest way to make them: open the app at `index.html#/record`, record
each phrase, press **Save file**, and copy the saved files into this folder.
The file names will already be correct.

Tips: use a quiet room, hold the phone about 20 cm away, say each phrase once
at a natural speed, and use the same speaker for a whole lesson.
