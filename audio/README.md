# Recordings

One file per phrase, named `<lessonId>-<phraseId>.<ext>`, for example
`greetings-azul.m4a`. Any common format works (m4a, mp3, webm, ogg, wav).
When the site is published, every recording is converted to an MP3 at an even
volume, because phones save in formats that not every browser can play (iPhone
recordings are fragmented MP4, which Safari won't play from a website).

The easiest way to make them: open the app at `#/record`, record each phrase,
press **Save file**, and upload the saved files to this folder on GitHub
(**Add file → Upload files**). The file names will already be correct. To
replace a recording, upload a new file with the same name.

Tips: use a quiet room, hold the phone about 20 cm away, say each phrase once
at a natural speed, and use the same speaker for a whole lesson.
